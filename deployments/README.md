# FairBatch Deployment Manifests (`deployments/`)

This directory stores the structured, git-tracked Ethereum Sepolia deployment manifest containing public contract addresses, transaction hashes, block numbers, gas usage, initialization parameters, and Etherscan links.

> **Security Rule:** Private keys and RPC API secrets are **never** written to `deployments/*.json` or `config/deployment.json`. The deployer private key is read only from the git-ignored root `.env` file during deployment.

## Files

| File | Purpose |
| :--- | :--- |
| [`sepolia.json`](./sepolia.json) | Generated by [`../scripts/deploy_sepolia.ps1`](../scripts/deploy_sepolia.ps1) upon live Ethereum Sepolia (`11155111`) deployment. Mirrors the live addresses in [`../config/deployment.json`](../config/deployment.json) (the single source of truth imported by the `viem` frontend). |

## How `deployments/sepolia.json` and `config/deployment.json` Are Generated

1. Compile the Fe contracts (`fe build`) so `./out/` artifacts exist.
2. Add `DEPLOYER_PRIVATE_KEY=0x...` to a local git-ignored `.env` file in the repository root.
3. Preview offline (zero network calls):
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts/deploy_sepolia.ps1 -DryRun
   ```
4. Execute live Sepolia deployment:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts/deploy_sepolia.ps1
   ```
   `deploy_sepolia.ps1` deploys access-controlled `fWETH` (`18` decimals) and `fUSDC` (`6` decimals), `FairBatch`, and `Faucet`, authorizes `Faucet` as token minter, funds `Faucet` with `2,000 fWETH` + `1,000,000 fUSDC`, seeds `100 fWETH` + `300,000 fUSDC` initial FM-AMM liquidity, verifies on-chain state, and writes both `deployments/sepolia.json` and `config/deployment.json`.
